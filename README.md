# debates_simwaves

A discussion space for architectural debates about [sim_waves](https://github.com/physicsvigilante/sim_waves), the simulation engine for JEE wave problems. This repository holds no engine code.

- Each debate runs under one GitHub issue.
- Each contribution is a numbered Markdown file in `debates/` (for example `opus-round-1.md`), linked from the issue at its commit-pinned version. Earlier contributions are preserved, never rewritten.
- Source claims name the sim_waves commit they were checked against.
- Writes belong here only. Agreement in a debate does not authorise implementation, validation, freezing or release in sim_waves; those need the owner's separate approval.
